This module turns the sales tax collected by
``l10n_us_sales_tax_engine`` into per-jurisdiction returns ready for
filing.

US state returns require collected tax to be reported broken down by
jurisdiction level — state, county, city and special districts. The
engine books each rate component as its own ``account.tax`` (tagged with
its jurisdiction level and state), so this module can aggregate the
posted tax lines into a return for one state over a filing period and
export a worksheet with the figures each state return expects.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Usage
=====

1. Go to *Accounting → Configuration → US Sales Tax → Returns*.
2. Create a return, pick the **State** and a **Period** (Monthly /
   Quarterly / Annual sets the dates; adjust as needed).
3. Press **Generate**. The return collects every posted customer invoice
   and credit note in the period whose tax was booked by the US Sales
   Tax Engine for that state, and lists the taxable base and tax
   collected per jurisdiction level.
4. Use the **Invoices** stat button to drill into the source documents.
5. Press **Export Worksheet** for a CSV of the breakdown to transcribe
   onto the state portal / Streamlined Sales Tax return.
6. Once submitted to the state, press **Mark Filed** to lock the return.

.. note::

   *Tax collected* is summed across every jurisdiction line because the
   full amount is remitted. *Taxable sales* is counted once (the
   state-level base), since the same sale is taxed by state, county and
   city simultaneously and summing the lines would multiply it.
